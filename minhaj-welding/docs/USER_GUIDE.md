# User Guide (Urdu/English)
1. **Rates** page: pehle apni asal rates set karein. Rate badalne se purane quotations nahi badalte.
2. **Calculators**: type chunein, naap likhein (ft + inch), total live nazar aata hai. Manual override ke liye wajah likhein. Save karein.
3. **Quotations**: + New Quotation, saved measurements chunein, create. Detail page par PDF / WhatsApp / Email / Invoice.
4. **Invoices**: Record Payment se advance/partial/final.
5. **Settings**: business info, message templates, icons.

## Phase 3
6. **Projects**: naya project banayein, BOQ (material/labour/equipment/transport/subcontractor) line by line add karein, milestones aur progress % log karein — profit/margin khud calculate hota hai (Contract Value − Actual Cost).
7. **Inventory**: item add karein, "Adjust Stock" se purchase/use/sale record karein — quantity khud update hoti hai. Low Stock badge min_stock se neeche jaane par.
8. **Catalog page** mein ab Materials aur Hardware/Addon Catalog bhi hain — Addon Catalog Quotation banate waqt "Insert from catalog" dropdown mein aata hai.
9. **Leads**: website ka contact form (agla phase) ya manual entry — "Convert" se seedha Customer ban jata hai.

## Phase 4
10. **Media Library**: images/videos/PDFs upload karein. 360° set ke liye ek object ke multiple angles se photos khींchein aur "Upload a 360° Photo Set" se ek saath select karein — drag karke ghumaya ja sakta hai (asli photos, ek image nahi).
11. **Website**: hero, services, gallery, testimonials, FAQs, footer — sab yahan se edit hota hai. Public site `/site` par (login ki zaroorat nahi) turant nazar aata hai.
12. **Custom Fields**: Customers/Projects/Measurements mein apni marzi ke extra fields add karein (jaise CNIC Number) — code change ki zaroorat nahi.
